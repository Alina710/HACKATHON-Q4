# Data Model: AI Agent with Retrieval-Augmented Capabilities

## Overview
This document outlines the data models for the AI agent with retrieval-augmented capabilities, including both internal agent models and integration with existing retrieval data structures.

## Agent-Related Data Models

### AgentSession
Represents a conversation session with the AI agent

- **session_id**: string - Unique identifier for the conversation session
- **thread_id**: string - OpenAI thread ID for maintaining conversation context
- **created_at**: datetime - Timestamp when session was created
- **last_activity**: datetime - Timestamp of last interaction
- **context_window**: integer - Number of conversation turns maintained (max 5)

### AgentResponse
Structure for responses generated by the AI agent

- **response_id**: string - Unique identifier for the response
- **session_id**: string - Reference to the conversation session
- **query**: string - Original user query
- **retrieved_chunks**: array of RetrievedChunk - Content chunks used to generate response
- **response_text**: string - Agent's generated response
- **confidence_score**: float - Confidence level in response accuracy
- **timestamp**: datetime - When response was generated

### RetrievedChunk
Structure for content chunks retrieved from Qdrant (reusing existing model)

- **id**: string - Unique identifier for the chunk
- **content**: string - The actual text content of the chunk
- **source_url**: string - URL where the content originated
- **title**: string - Title of the source document
- **chunk_index**: integer - Position of chunk in original document
- **score**: float - Similarity score from vector search
- **metadata**: object - Additional metadata associated with the chunk

## Integration with Existing Models

### Connection to TextChunk (book_ingestion/chunker.py)
The agent will work with the existing `TextChunk` dataclass:

```python
@dataclass
class TextChunk:
    id: str
    content: str
    source_url: str
    title: str
    position: int
    metadata: Dict[str, str]
```

### Connection to DocumentChunk (backend/main.py)
The agent will also interface with the existing `DocumentChunk`:

```python
@dataclass
class DocumentChunk:
    id: str
    content: str
    source_url: str
    title: str
    chunk_index: int
    metadata: Dict[str, str]
```

## Validation Rules

### AgentSession Validation
- session_id must be unique across all sessions
- thread_id must be a valid OpenAI thread identifier
- context_window must be between 1 and 5
- created_at must be before last_activity

### AgentResponse Validation
- response_text must not exceed 2000 characters
- confidence_score must be between 0.0 and 1.0
- retrieved_chunks must contain at least 1 chunk for non-error responses
- query must not be empty

### RetrievedChunk Validation
- content must not be empty
- score must be between 0.0 and 1.0
- source_url must be a valid URL format

## State Transitions

### AgentSession States
1. **CREATED**: Session initialized, waiting for first query
2. **ACTIVE**: Session has received at least one query and response
3. **INACTIVE**: Session has been idle beyond timeout threshold
4. **ENDED**: Session explicitly ended by user or system

### Response Generation Flow
1. **QUERY_RECEIVED**: User query captured
2. **RETRIEVAL_STARTED**: Retrieval tool called
3. **RETRIEVAL_COMPLETED**: Chunks retrieved from Qdrant
4. **RESPONSE_GENERATING**: Agent processing chunks
5. **RESPONSE_READY**: Response generated and validated
6. **RESPONSE_SENT**: Response delivered to user

## Relationships

- One AgentSession can have many AgentResponse objects (1:N)
- One AgentResponse can reference many RetrievedChunk objects (1:N)
- RetrievedChunk objects map directly to existing TextChunk/DocumentChunk objects
- AgentSession connects to OpenAI's thread system via thread_id
