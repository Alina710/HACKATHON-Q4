# Reusable UI Components for Documentation

## Available Components

### 1. Buttons
- **Primary Button**: `.button.button--primary` - For primary actions
- **Secondary Button**: `.button.button--secondary` - For secondary actions
- Responsive and accessible with proper focus states

### 2. Callouts/Admonitions
- **Primary**: `.alert.alert--primary` - For general information
- **Success**: `.alert.alert--success` - For positive information
- **Info**: `.alert.alert--info` - For informational notes
- **Warning**: `.alert.alert--warning` - For warnings
- **Danger**: `.alert.alert--danger` - For errors/warnings

### 3. Code Blocks
- **Standard**: Automatic styling for fenced code blocks
- **Line Highlighting**: Use `/* highlight-line */` comment in code
- **Inline Code**: Automatic styling for inline code elements

### 4. Tables
- **Responsive**: Automatically wraps in scrollable container
- **Styled**: Clean, accessible table styling
- **Dark Mode**: Proper dark mode support

### 5. Images & Media
- **Figures**: `.figure` class for image containers
- **Centered**: `.figure--center` for centered images
- **Captions**: `.figure__caption` for image descriptions

### 6. Navigation Elements
- **Breadcrumbs**: Automatic breadcrumb navigation
- **Sidebar**: Enhanced sidebar with better hover states
- **Navbar**: Improved navbar with active states

## Usage Guidelines

### Colors
- Primary color: #2563eb (modern blue)
- Dark theme primary: #60a5fa
- All components follow consistent color scheme

### Typography
- Improved font stack for better readability
- Enhanced heading hierarchy
- Better paragraph spacing

### Accessibility
- All components have proper focus indicators
- Sufficient color contrast ratios
- Keyboard navigable elements

### Responsive Design
- All components adapt to different screen sizes
- Mobile-first approach
- Touch-friendly elements
