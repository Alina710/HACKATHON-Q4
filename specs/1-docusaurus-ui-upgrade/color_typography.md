# Current Color Scheme and Typography Documentation

## Color Scheme

### Primary Colors
- Light mode primary: #2e8555 (green)
  - Darker variants: #29784c, #277148, #205d3b
  - Lighter variants: #33925d, #359962, #3cad6e
- Dark mode primary: #25c2a0 (teal)
  - Darker variants: #21af90, #1fa588, #1a8870
  - Lighter variants: #29d5b0, #32d8b4, #4fddbf

### Special Colors
- Code line highlight: rgba(0, 0, 0, 0.1) in light mode, rgba(0, 0, 0, 0.3) in dark mode
- Default Infima colors (not overridden): Various shades for backgrounds, text, etc.

## Typography

### Current Settings
- Code font size: 95% of default (set via --ifm-code-font-size)
- Default Docusaurus typography (Infima framework)
- No custom font families specified
- Standard heading hierarchy (H1-H6) using Infima defaults

### Font Stack
- Default Docusaurus/Infima font stack
- Sans-serif primary font
- Monospace for code elements

## Spacing and Layout
- Default Infima spacing system
- Standard Docusaurus layout components (navbar, sidebar, main content area)
- Default padding and margins from Docusaurus theme

## Accessibility Considerations
- Current contrast ratios need verification against WCAG 2.1 AA standards
- Focus indicators use default browser/Infima styles
- No custom accessibility enhancements currently implemented
